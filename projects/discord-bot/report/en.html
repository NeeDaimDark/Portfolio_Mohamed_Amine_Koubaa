At a glance

Discord Bot (called MCP Bot inside the server) helps a development team stay organised where it already talks: Discord. Members type short slash commands to log what they did, ask for a summary of yesterday or a plan for today, and check the team's progress.

Behind each command, an AI model reads the team's recorded work and replies with summaries, recommendations and answers. The bot was built for a team working with the Model Context Protocol (MCP), so it also acts as a learning companion for MCP, Docker and AI topics.

Who it's for

Developers

Log tasks and progress in seconds, get feedback from the AI and ask technical questions in a private chat.

Team leads

See team statistics, progress analytics and AI recommendations on what to prioritise next.

New team members

Follow the built-in guide, learn MCP step by step and get daily tips.

Server administrators

Organise the server in minutes with a guided setup and pinned explanations in every channel.

The problem it solves

In a busy team, daily progress gets lost in chat threads, nobody has a clear view of who is moving forward or blocked, and newcomers struggle to find answers about a technology as new as MCP.

The bot gives this work a home: every update is recorded in a structured way, the AI turns it into summaries and next steps, and questions get an answer immediately instead of waiting for a colleague.

Main features

Private AI chat

/chat creates a channel only the member can see; /ask answers questions about MCP, AI and the team's projects there.

Problem solver

/challenge-solver explains the likely root cause of a blocker, the steps to fix it and how to prevent it.

Development updates

/dev-update records the project, type of work, status and tools used, and the AI adds an assessment and a recommendation.

Team insights

/ai-insights and /team-progress analyse the team's recorded work and suggest priorities.

Daily tasks

/task-completed logs finished work; /yesterday-summary and /today-plan give an AI summary and a plan for the day.

Motivation and streaks

Consecutive active days build a streak, unlock milestones with points and appear on the leaderboard.

Learning

/mcp-learn and /daily-tip share learning resources and tips on MCP, Docker and AI, by level.

Organised channels

/channel-setup posts a setup guide and an explanation card in each channel; each command only works in its own channel.

Fair use

Each member can run up to ten commands per minute, so the AI stays available for everyone.

How it works

A member types a command

Discord sends the slash command to the bot's web service, which checks that the request really comes from Discord.

The bot checks the context

It makes sure the command is allowed in this channel and that the member has not exceeded the usage limit.

Work is recorded

Tasks, updates, streaks and chat sessions are saved in the database, building the team's history.

The AI answers

The bot sends a ready-made prompt with the relevant data to the AI model and gets back a summary, an answer or a recommendation.

The reply appears in Discord

The answer is posted as a clear card, in the channel or privately, depending on the command.

Technologies

Bot service

Node.jsRuns the bot.
ExpressReceives the commands Discord sends to the bot's web address.
Discord Interactions APIDelivers slash commands, verifies their signature and lets the bot create channels and post messages.

AI

Groq with LLaMA 3.3 70BWrites summaries, answers, insights and recommendations.
Prompt libraryA shared set of instructions loaded once, so answers stay consistent and use fewer tokens.
Key rotation and cacheSwitches to another AI key when one reaches its limit and reuses recent answers.

Data & hosting

MongoDB AtlasStores tasks, development updates, streaks, achievements, learning resources and chat sessions.
RenderHosts the bot's web service in the cloud.
